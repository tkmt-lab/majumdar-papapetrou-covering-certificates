# R029 A-1：区間証明書の意味と導出

読み手は統括と、同じ入力から実装を点検する検証者。数値判定は `coverage-audit.json` に置く。本書だけで成功を宣言しない。

## 対象と入力

`inputs/SPEC.md` の4次元の自律ODEを使用する。状態は `(x,z,vx,vz)`、断面は `z=0,vz>0`、初期族は `iota(q,w)=(q,0,w,sqrt(1-w²))`。`boxes.json` の十進文字列を正確な有理数とする。元のA-1三箱の中心、二基底、二半径は固定し、A-2へ交換しない。`geometry-pilot.json` の有理数による頂点・分離検査は、異なる箱のq射影が互いに離れることを示す。

各箱を `c+u_vec*u+s_vec*s` と書く。`strips.dat` の5本の部分帯は、uを有理区間に限定し、sは元の全区間[-1,1]とする。端点は自作の区間点積分による二分探索で選んだ。探索の格子点は全帯の証明に数えない。同じ出発箱に属する帯どうしはu区間で離れている。入力の出所と、先行する非厳密数値結果への露出は `READ-LOG.md` に記した。無露出の第三者検証ではない。

## 算術と初期集合

`solver.cpp` のI型は、binary64の各基本四則演算・平方根の結果をnextafterで外側へ1ULP広げる。厳密な零との演算だけは恒等式を使う。有限性、分母の零、平方根の非負性を検査する。整数の分子・分母が2^53未満であることを検査して十進値を囲う。コンパイルは `-O2 -ffp-contract=off -fno-fast-math`。IEEE-754の最近接演算と正しく丸めるsqrt/nextafterを信頼基盤に含む。形式検証されたライブラリという主張ではない。

JSONの17桁端点はbinary64へround-tripする表現であり、監査では同じbinary64値をFractionで正確な有理数へ戻す。表示文字列を十進の厳密な包含端点と解釈しない。報告の短い表示範囲はさらに外向きに丸める。

初期各セルを中心・固定2変数・4次元の誤差箱で

`X = c + C ξ + B η,  ξ∈[-1,1]², |η_j|≤r_j`

と囲う。q,wはアフィン式そのものを囲い、vzは中心wにおける一次Taylor式と剰余 `|Δw|²/[2(1-w_range²)^(3/2)]` で囲う。中心・行列の丸め誤差もrへ含める。真のnull初期グラフの全点が入る。包含のための4次元箱に非null点が混ざっても、SPECの滑らかな拡張ODEで伝播すれば真のnull族を含み続ける。

## 一歩の存在、Taylor剰余、変分の包含

h>0ごとに直積箱B0について `X+[0,h]f(B0) ⊂ int(B0)` を検査する。fは分母が零でない領域で滑らかであり、連続依存と局所解の延長によって全初期値の時刻[0,h]の解がB0に存在する。確認後、`B←B∩(X+[0,h]f(B))` を2回行っても真のtubeを保つ。

全tubeで `r±>1/5` と `x²+z²<64` を確認する。下界を出せなければhを半減し、それでも通らなければセルは未証明。境界の検査不通過を物理的な地平面への落下と解釈しない。

流れの時間Taylor係数をa_k、次数をN=10とする。係数はODEの形式冪級数の再帰によって区間演算で作る。中心解の終点は

`Φ_h(c) ∈ Σ_(k=0..N) a_k(c) h^k + a_(N+1)(B) h^(N+1)`。

変分V'=Df(Φ_t(x))V, V(0)=Iについて `L≥sup_B ||Df||∞`、`a=hL<1/2` とする。`||V-I||∞≤exp(a)-1≤a/(1-a)=e` なので、全成分を `I+[-e,e]` で囲う。各成分の時間Taylor定理を変分方程式自体へ適用すると

`DΦ_h(X) ⊂ Σ_(k=0..N) Da_k(X) h^k + Da_(N+1)(B) V_tube h^(N+1)`。

これは未知の中間時刻を含む位置の剰余を初期値で微分した式ではない。`d^k V/dt^k=k! Da_k(Φ_t(x))V(t)` を変分の剰余に用いる。Da_kは4成分の自動微分と区間冪級数を併用して囲う。中心剰余≤1e-13、変分剰余の∞ノルム≤1e-11を一歩の採用条件にする。

受理する刻みhは1/16の二分で得た二進有理数であり、上限60までの時刻の加算はこの実行の範囲でbinary64に正確に表現できる。剰余に使うhの冪は別途区間演算で囲う。

## 形状を保つ包含更新

Jを一歩の変分包含、MをJの成分中点とする。`C_new=mid(M C)`、`B_new`は`mid(JB)`のQRで得る実数行列を選ぶ。QRを厳密な直交行列だと仮定しない。保存されたbinary64行列B_newそのものの逆を区間Gauss消去で囲い、pivotに零が入ると失敗する。

平均値表示により新しい誤差は

`B_new^-1 [ (Φ_h(c)-c_new) + ((J-M)C + MC-C_new) ξ + JBη ]`

で囲われる。各成分の絶対上界を新しいrとする。Cの二変数の相関を保ち、全状態を毎回直積箱へ置き換えることによる膨張を抑える。基底の選び方が良くなくても包含式は維持される。平均値に用いる中心から各点までの線分はXの外側直積箱内にあるため、その箱上のJ包含で十分である。

## 最初の上向き帰還と時刻補正

最初の一歩で全tubeのvz>0と終点z>0を示す。正側にいる間、tubeのz>0、またはvz>0で開始点から単調増加することにより零点がないと判定する。z=0を含みvz<0の窓を見つけたら、その窓全体のvz<0を保って終点z<0まで進める。負側でも同様に零点のない一歩と単調な下向き一歩を区別する。

次にz=0を含みvz>0の窓を見つけ、窓の始点z<0、終点z>0、全窓vz≥ν>0を全初期値で示す。各初期値の帰還時刻τは窓内で存在・一意であり、途中の零点の排除と合わせて最初の次の上向き帰還である。各成功セルの出力には窓、端点符号、ν、下向き窓の数1、全tubeのD境界の余裕が含まれる。上限60や未解決の窓は不存在を意味しない。

到達前の共通固定時刻での集合をX0、そのz成分をz0<0とする。窓全体の `(vx/vz, f_vx/vz)` をKで囲う。zを積分変数にすると

`(x,vx)_return = (x,vx)_0 - K_avg*z0`,  `K_avg∈K`。

任意の点k0を選び、右辺を `(x,vx)_0-k0*z0 + (k0-K)*z0` と評価する。最初の線形項はDoubletonのCとBの相関を保ち、行き先の箱の逆座標行列の行を直接掛ける。各初期値で異なるτでの像を包含しており、固定時刻の像をPの像と取り違えない。

## 全内部・全辺を検査する有限分割

C1は各部分帯の全長方形、C2L/C2Rは左右それぞれの全s辺を対象とする。セルの座標は二進有理数で、二分の子は閉区間の境界だけを共有し親全体を覆う。各葉で帰還が証明され、C1では `-1<S_lower≤S_upper<1`、C2Lでは `U_upper<-1`、C2Rでは `U_lower>1` を要求する。

`check_coverage.py` は根から全ノードを独自に巡回し、親子の端点をFractionで比較し、全葉に対応する成功証明書と厳密不等式があることを点検する。未処理セル・時間切れ・未証明が一つでもあればその条件は不通過とする。分割に隙間がないことの検査はODE実装の再証明ではない。

## 五本が全通過した場合の力学的帰結

各出発帯K_ijから元の行き先N_jへのC1/C2が通った場合だけ以下を適用する。同じN_jにある次の帯K_jkはsの半径を変えず、uだけを真に内側の区間[a,b]へ縮めたもの。新しいu座標は `(U_j-(a+b)/2)/((b-a)/2)` なので、左右の `U_j<-1` と `U_j>1` は各K_jkの左右の外側も跨ぐ。よってK_ijは全ての許されたK_jkを被覆する。

5帯を状態にした隣接行列Bで `B_(ij,jk)=1` とする。帯は同じ元箱でも異なる元箱でも互いに離れている。C1/C2からs像を0へ縮め、u像を2uへ変形するhomotopyは入口・出口を避け、出口方向のdegreeは1である。SPECが採用した被覆列の実現定理とコンパクト性により、Bの許された符号列を実現する不変集合が得られる。各帯上の最初の帰還は横断性によって近傍で連続、互いに離れた帯の符号化は連続であり、帰還写像からBのshiftへの全射の半共役を与える。

元の3状態行列Aは `[[1,1,0],[0,0,1],[1,1,0]]`。5帯は辺による状態分割なので、Bはそのline graphの行列である。証明書の独立な整数多項式計算では `det(λI-A)=λ(λ²-λ-1)`、`det(λI-B)=λ³(λ²-λ-1)` を確認する。従ってρ(A)=ρ(B)=(1+sqrt(5))/2。全通過の場合、帰還一回あたりの位相エントロピーはlogρ以上となる。下限の十進値は整数平方根と `logρ=2Σ_(k≥0)(sqrt(5)-2)^(2k+1)/(2k+1)` の有理数計算で囲う。

元の各N_iの全正方形から複数のN_jへの強いC1が成立したとは主張しない。軌道の一意性・共役・双曲性、流れの単位時間当たりのエントロピー、新規性、一般相対論の模型の外への適用は追加の検証を要する。モデル対応は提供されたSPECの仮定を採用し、この仕事で原論文との対応を再監査していない。
